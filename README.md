# Action Trauma — Facturation et gestion

Application web installable (téléphone et ordinateur) : soumissions, factures, évènements, employés, inventaire, paies.

- Hébergement : GitHub Pages (ce dépôt, branche `main`).
- Données et connexions : Supabase (projet « Outil gestion interne »). Aucune donnée n'est stockée dans ce dépôt.
- `supabase.sql` : script de création de la base (déjà exécuté).
- `config.js` : adresse et clé **publique** Supabase.
